Report with embedded UML

This document demonstrates inline PlantUML source blocks that a preprocessor converts to PNG images before EPUB packaging. The agent writes ONE self-contained HTML file; rendering happens at conversion time.

1. Class diagram

The two-stage pipeline used by this project:

@startuml
!theme cerulean-outline
skinparam dpi 180
class ReportAgent {
  +generate_html(): str
  -render_diagrams(): list[Path]
}
class HtmlToEpub {
  +convert(html: str): bytes
}
class KindleSender {
  +send(epub: bytes): None
}
ReportAgent --> HtmlToEpub : uses
HtmlToEpub --> KindleSender : produces input for
@enduml

2. Sequence diagram

Round-trip from a user prompt to a Kindle device:

@startuml
!theme cerulean-outline
skinparam dpi 180
actor User
participant Agent
participant "kindle-mcp" as MCP
participant "Kindle device" as K

User -> Agent : prompt
note over Agent : draft HTML\n+ UML blocks
Agent -> MCP : send_html_to_kindle(html)
note over MCP : render diagrams → PNG\nhtml2epub
MCP -> K : email .epub
K --> User : displays book
@enduml

3. Activity diagram

The preprocessor's per-block control flow:

@startuml
!theme cerulean-outline
skinparam dpi 180
start
:parse HTML;
repeat
  :extract one plantuml block;
  :sha1(source);
  if (PNG already cached?) then (yes)
    :reuse cached png;
  else (no)
    :shell out to plantuml.jar;
    :write png;
  endif
  :replace block with img tag;
repeat while (more blocks?)
:hand HTML to html2epub;
stop
@enduml
